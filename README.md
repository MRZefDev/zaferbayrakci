- **FontAwesome:** For professional iconography.

## ✨ Key Features
- **Modern Dark UI:** A high-contrast aesthetic using a gold and obsidian color palette.
- **Responsive Layout:** Sidebar-based navigation for desktop and a fluid content area.
- **Interactive Elements:** Smooth scroll transitions, hover effects on experience cards, and custom-styled certification boxes.
- **Content Protection:** Implemented basic JavaScript listeners to prevent unauthorized inspection (context menu and specific hotkeys).
- **Digital Resume:** Organized sections for Summary, Experience, Certifications, Education, and Social Links.
